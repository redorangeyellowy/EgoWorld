EgoWorld: Translating Exocentric View to Egocentric View using Rich Exocentric Observations

Junho Park1, Andrew Sangwoo Ye2, Taein Kwon3†
1AI Lab, LG Electronics 2KAIST 3Visual Geometry Group, University of Oxford

† Corresponding author

arXiv Code Citation

TL;DR. EgoWorld reconstructs a first-person view from a single third-person image by combining sparse geometry, predicted 3D egocentric hand pose, and textual scene understanding in a two-stage generation pipeline.

Abstract

Egocentric vision is essential for both human and machine visual understanding, particularly in capturing the detailed hand-object interactions needed for manipulation tasks. Translating third-person views into first-person views significantly benefits augmented reality, virtual reality, and robotics applications. However, existing exocentric-to-egocentric translation methods depend heavily on 2D cues, synchronized multi-view settings, or unrealistic assumptions such as having an initial egocentric frame and relative camera poses available at inference time.

EgoWorld addresses these limitations with a two-stage framework that reconstructs an egocentric image from rich exocentric observations, including projected point clouds, 3D hand poses, and textual descriptions. The system first predicts observation signals from a single exocentric image, then uses them to guide diffusion-based inpainting for dense and semantically coherent egocentric view synthesis. Across the H2O and TACO datasets, EgoWorld achieves state-of-the-art performance and shows strong generalization to new objects, actions, scenes, subjects, and real-world captures.

Method Overview

EgoWorld separates observation prediction from final image synthesis so the output remains grounded in geometry and semantics.

Stage 1

Exocentric observation \( \Phi_{exo} \)

Given a single exocentric image \( I_{exo} \), EgoWorld predicts a sparse egocentric RGB map \( S_{ego} \), a 3D egocentric hand pose \( P_{ego} \), and a textual description \( T_{exo} \).

Stage 2

Egocentric reconstruction \( \Phi_{ego} \)

The sparse map, predicted pose, and language description are fused to generate the final egocentric image \( \hat{I}_{ego} \), allowing recovery of unseen object and scene content.

Formulation

\[ S_{ego}, P_{ego}, T_{exo} = \Phi_{exo}(I_{exo}),\\ \hat{I}_{ego} = \Phi_{ego}(S_{ego}, P_{ego}, T_{exo}). \]

Core Results

EgoWorld consistently reconstructs more plausible first-person views than prior methods, especially beyond the hand region.

Real-World Generalization

Using only a single smartphone image as input, EgoWorld produces realistic egocentric views in unseen real-world settings. Compared with CFLD, the generated images stay more natural and better aligned with the actual interaction scenario.

Analysis

The ablations show that EgoWorld benefits from multimodal conditioning, a diffusion-based completion backbone, and stable exocentric-to-egocentric pose prediction.

01

Effect of Conditioning Modalities

Text improves unseen object reconstruction, while pose cues improve hand fidelity. EgoWorld performs best when both signals are used together.

02

Backbone of Image Completion

Compared with MAE and MAT variants, the latent diffusion backbone preserves both local hand-object details and overall scene consistency more effectively.

03

3D Egocentric Hand Pose Estimation from Exocentric View

The predicted egocentric hand pose stays close to the target interaction and provides useful structure for both geometric alignment and final generation.

04

Incorrect Textual Description Guidance

When the language description is intentionally wrong, the generated object changes accordingly, showing that the model genuinely uses textual semantics during synthesis.

05

Generation Consistency

Even though diffusion models are stochastic, repeated generations from the same exocentric input remain visually coherent, suggesting that EgoWorld is stable enough for practical use.
